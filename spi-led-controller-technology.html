SPI LED Controller Technology

How SPI controllers send pixel data down addressable LED strip, so every LED can show its own colour and effects can run along the strip.

Overview

What are SPI LED controllers?

Addressable LED strip has a small driver IC in every pixel, or every few LEDs. An SPI controller sends a serial data signal along the strip, and each IC picks out its own colour and brightness, so every pixel can be set on its own.

That makes moving effects possible: chases, meteors, flows and rainbows that run along the strip. Our range includes standalone controllers with built-in effects and RF remotes, and DMX to SPI decoders that bring pixel strip into a DMX512 lighting scheme. They drive single colour, RGB and RGBW pixel strip.

  • SPI (TTL) data out to pixel ICs
  • Up to 2048 pixels per controller
  • RF 2.4GHz remote, panel or DMX512 control
  • 5–24V DC supply
  • Single colour, RGB and RGBW pixel strip

The technology

How an SPI controller works

The controller sends a stream of colour data down the DATA line. The first pixel IC keeps the first set of values, three for RGB or four for RGBW, and passes the rest on to the next pixel, and so on to the end of the strip.

The controller repeats the stream many times a second, changing the values to create effects. It needs to know the number of pixels and the colour order of the strip, and on some models the IC type.

The strip takes its power from the DC supply. On long runs, inject power at several points along the strip so the far end does not dim.

Selection & set-up

Choosing and setting up an SPI controller

  • Check the IC: confirm the controller supports the strip's pixel IC, and whether it is one-wire or two-wire.
  • Count the pixels: make sure the run is within the controller's pixel limit for RGB or RGBW.
  • Choose the control: an RF remote or panel for standalone effects, or a DMX to SPI decoder for a DMX scheme.
  • Match the voltage: use a DC supply that matches the strip, 5V, 12V or 24V, within the controller's input range.
  • Set the strip up: set the pixel count and colour order, and the IC type or speed where needed.
  • Feed the power: inject power along long runs, and keep the data cable from the controller short.

FAQ

SPI LED controller questions

An SPI LED controller sends a serial digital data signal to addressable (pixel) LED strip. Each pixel has its own driver IC that reads its colour from the data stream and passes the rest along, so every pixel can show a different colour and moving effects can run along the strip.

A standalone SPI controller runs its own built-in effects and is set from an RF remote or panel. A DMX to SPI decoder, such as the LT-DMX-1809, DMX-SPI-202 or DMX-SPI-203, takes a DMX512 signal from a lighting console and converts it to SPI, so the pixels can be programmed as part of a larger DMX scheme.

The SPIR3 and SPIR3-M drive 2048 single colour, 1536 RGB or 1024 RGBW pixels, the SPE-103E up to 2048 pixels and the LT-SPI-16S 8 to 1020 pixels. In DMX decode mode, the DMX-SPI-202 controls 170 RGB pixels from 510 channels, or up to 1020 pixels using its virtual pixel function.

Most controllers support the common one-wire ICs such as WS2811, WS2812B, TM1809, UCS1903 and SK6812. The LT-SPI-16S, DMX-SPI-202, DMX-SPI-203 and SPE-103E also support two-wire ICs with a separate clock line, such as APA102, WS2801 and LPD8806. Check the datasheet for the full list.

Not on the SPIR3 and SPIR3-M, which detect the chip automatically. On the LT-SPI-16S the IC type, pixel count and RGB order are set from the M16S remote, and on the DMX-SPI-202 and DMX-SPI-203 they are chosen on the OLED display. On the LT-DMX-1809, DIP switch 10 selects 800K or 400K data speed.

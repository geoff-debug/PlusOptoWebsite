DMX CC LED Driver Technology

How DMX512 constant current drivers give individual, deep-dimming control of LED fittings, and how to address, wire and choose them.

Overview

What is a DMX CC LED driver?

A DMX constant current (CC) driver is a mains LED driver with a DMX512 control input. It supplies a fixed current to an LED module and dims it to the level sent on its DMX channel, so every fitting can be controlled individually from a lighting desk, DMX controller or building management system. DMX is the standard for architectural, stage and entertainment lighting.

Our range includes Ltech SE series drivers up to 20W with DMX/RDM and dimming down to 0.01%, and Sunricher SRP-2106 drivers at 50W and 75W with 250–1500mA output and a built-in address display. Ltech LT-84A and LT-834A modules convert DMX or DALI to 0-10V, PWM or mains phase-cut dimming for other drivers and lamps.

  • Individual control of each fitting on a DMX512 line
  • Constant current output set by DIP switch or app
  • Deep, flicker-free dimming to IEEE 1789
  • RDM for remote addressing on Ltech SE models
  • Tuneable white 2-channel model

The technology

How DMX dimming works

A DMX controller sends a continuous stream of data called a universe: 512 channels, each holding a level from 0 to 255. The stream travels over a daisy-chained twisted-pair cable from driver to driver, with a 120Ω terminator at the end of the line.

Each driver is set to a start address and reads only its own channel, or two consecutive channels for tuneable white. Drivers with the same address act together.

The driver then sets its constant current output to that level using high-frequency PWM. With RDM, the controller can also find drivers, set their addresses and read their status over the same cable.

Selection & set-up

Choosing and installing a DMX CC driver

  • Match the current: set the driver to the LED module's rated current before switching on.
  • Check the voltage: the module's forward voltage must sit within the driver's output range.
  • Plan the addresses: give each driver, or group of drivers, its own start address; 2-channel models use two.
  • Daisy-chain the cable: run screened twisted-pair data cable from driver to driver, with no spurs or star joints.
  • Terminate the line: fit a 120Ω terminator at the last driver on each DMX line.
  • Split large systems: use a DMX splitter or amplifier for branches or more devices than one line allows (normally 32).

FAQ

DMX CC driver questions

A DMX constant current (CC) driver is a mains LED driver with a DMX512 control input. It supplies a fixed current to an LED module and dims it to the level sent on its DMX channel, so each fitting can be controlled individually from a lighting desk, DMX controller or building system.

Each driver is given a start address from 1 to 512 and listens to that DMX channel, or to consecutive channels for 2-channel tuneable white models. The address is set with buttons and a display on the Sunricher SRP-2106 drivers, or by RDM or the app on the Ltech SE series. Drivers given the same address respond together.

RDM (Remote Device Management) is a two-way extension of DMX512 that runs on the same cable. A controller that supports RDM can find each driver, set its DMX address and read its status remotely, without access to the driver itself. The Ltech SE-W1M and SE-W2M drivers support RDM.

Run the DMX line as a daisy chain from driver to driver using screened twisted-pair data cable, not a star or spur layout, and fit a 120 ohm terminator at the last driver. Use a DMX splitter or amplifier to create extra branches, or if a line has more devices than the DMX standard allows (normally 32).

The Ltech SE-W1M and SE-W2M drivers dim from 100% down to 0.01% with high-frequency PWM at 3600Hz, which is flicker free to IEEE 1789. Soft-on and fade-in functions make changes smooth and comfortable.

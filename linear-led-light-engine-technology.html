Linear LED Light Engine Technology

How linear LED light engines replace fluorescent tubes in luminaires, how they are driven and connected, and how to choose the right module for your design.

Overview

What is a linear LED light engine?

A linear LED light engine is a rigid circuit board populated with high-efficiency mid-power LEDs, designed as the light source for linear luminaires such as battens, troffers, panels, suspended linears and high bays. Combined with a matched constant-current LED driver, it forms a complete lighting system that replaces fluorescent tubes with a more efficient, longer-lasting and more consistent light source.

Our linear portfolio is based on Philips Fortimo modules from Signify. It includes Fortimo LED Line for general lighting, LED Line High Flux for high ceilings, slim Fortimo LED Strip in lengths from 0.25ft to 5ft, and ultra high efficiency UHE modules at up to 229 lm/W. Modules offer 3 SDCM colour consistency, CRI above 80 or 90, colour temperatures from 3000K to 5000K, and Zhaga-compliant form factors.

  • Efficacy up to 229 lm/W for lower energy use
  • Lifetimes above 50,000 and up to 100,000 hours
  • 3 SDCM colour consistency between luminaires
  • Zhaga-compliant form factors for easy design-in
  • Lengths from 0.25ft to 5ft to suit any luminaire size

The technology

How a linear LED system works

Linear light engines are driven by a constant-current LED driver, which holds the current through the LEDs at a set value. The light output of each module is set by that current, so the same module can be run harder for more lumens or softer for higher efficacy and longer life.

Each module has a forward voltage that scales with its length. Connected in series, module voltages add together, so several short modules can make one long run as long as the total sits within the driver's voltage window. Connected in parallel, the driver current is shared between modules.

The Zhaga standard defines the size, fixing points and electrical interface of compliant modules, so a luminaire can be designed once and use interchangeable light engines.

Design-in

Designing a linear luminaire

  • Set the target lumens and efficacy for the luminaire, then choose the module family and length to suit.
  • Choose the drive current: higher current gives more light, lower current gives higher efficacy and longer life.
  • Add up the forward voltages of modules in series and check the total sits within the driver's output window.
  • Select a matched constant-current driver, ideally programmable, with DALI or 1–10V dimming if required.
  • Manage heat by mounting modules on a metal surface and keeping within the rated operating temperature.
  • Choose optics or diffusers to control glare and give the light distribution the application needs.

Series voltage example

Using Fortimo LED Strip MF HV6 typical forward voltages:

  • 1 x 2ft module: 44.2V
  • 2 x 2ft modules in series: 88.4V
  • 1 x 4ft module: 88.4V

Two 2ft modules give the same voltage as one 4ft module, so the same driver can serve both luminaire designs. Always confirm against the module and driver datasheets.

FAQ

Linear light engine questions

A linear LED light engine is a rigid LED board designed as the light source for linear luminaires such as battens, troffers, panels and high bays. Used with a matched constant-current LED driver, it replaces fluorescent tubes with a more efficient, longer-lasting and more consistent light source.

Zhaga is an industry consortium that standardises the physical, thermal and electrical interfaces of LED light engines. A Zhaga-compliant linear module follows a standard form factor, so luminaires can be designed once and modules from compliant suppliers used interchangeably.

Linear modules are driven by a constant-current LED driver and are usually connected in series, in parallel or a combination. In series, the forward voltages add up, so the total must sit within the driver's output voltage window. In parallel, the driver current is shared between the modules.

Choose a constant-current driver whose output current matches the module's operating current and whose voltage window covers the total forward voltage of the connected modules. Programmable drivers let one driver type serve several luminaire sizes and light outputs. We can recommend a matched driver for your design.

SDCM measures how closely modules match in colour; 3 SDCM means differences are barely visible, so luminaires side by side look the same. CRI measures how naturally colours are shown; CRI above 80 suits offices and industry, while CRI above 90 suits retail, healthcare and hospitality.
